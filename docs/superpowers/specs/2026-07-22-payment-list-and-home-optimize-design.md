# 支付清单与首页优化设计

**日期：** 2026-07-22  
**状态：** 待实现  
**端：** Android App + 微信小程序（双端对等）  
**会话偏好：** 改码收尾执行 `sh oneClickSetup`

## 1. 目标

- 纠正支付清单大类金额口径（「实际」不得再用 effectiveCost）
- 支持按阶段 / 分类切换分组，解决「灯具」等分类大类不出现的问题
- 补齐数量展示、列表形态、未付自动计算、抽屉宽度
- 首页合并预算相关模块，去掉双执行进度条
- 增加搜索引导页与标签图标（预置 + 相册）

## 2. 分期（推荐方案 2）

| 期 | 范围 | 验收要点 |
|----|------|----------|
| **P0** | 支付清单重构、未付自动算、抽屉 3/4 | 按分类可见灯具大类；三金额口径正确 |
| **P1** | 首页指标合并 | 无预算/预计执行条；总预算为主 + 超支/节省 % |
| **P2** | 搜索引导页、标签图标 | 名称即时匹配；标签可设预置/自定义图标 |

## 3. 背景：分组维度

预算项有三维标签：

- **阶段 `stage`**：水电、泥木、软装…
- **分类 `category`**：家具、家电、软装、灯具（可自定义）…
- **空间 `space`**：客厅、主卧…

**现状：** 清单 `groupBy { stage }`。模板项「灯具」的 stage/category 均为「软装」。用户在标签管理新增「灯具」并只改 **分类** 时，按阶段分组仍落在「软装」下。

**本期：** 支持切换按 stage / category 分组；**不做**按空间分组。

## 4. P0 · 支付清单

### 4.1 改名

全端「预算清单」→「支付清单」（Tab、标题、空态及相关文案）。

### 4.2 分组与列表形态

| 能力 | 行为 |
|------|------|
| 分组维度 | 默认 **阶段**；可切 **分类**；偏好持久化（UserPrefs / 小程序 prefs） |
| 列表形态 | **二级列表**（大类折叠，默认） / **单列表**（项平铺，按分组键排序，组间可插分隔条）；偏好持久化 |
| 空分组名 | 显示为「未分类」 |

### 4.3 大类头指标

| 字段 | 口径 |
|------|------|
| **实际支付** | Σ 状态为已付的付款金额 |
| **预算** | Σ 预算金额 |
| **预计要支付** | Σ `effectiveCost`（有合同价用合同价，否则预算） |
| **已支付** | 有已付记录的**项数** + 已付金额合计 |
| **待支付** | 仍有未付或处于待购买的**项数** + 待付金额（未付付款合计 + 待购买项 effectiveCost） |

> 修正：现状大类「实际」使用 effectiveCost，应改为「预计要支付」口径；「实际支付」仅统计已付。

### 4.4 筛选 Tab

全部 / 待购买 / 付款中 / 已结清，各展示：

- **条数**：该状态下预算项数量  
- **金额**：该状态下项的 `effectiveCost` 合计  

格式示例：`付款中 12 · ¥18万`（金额格式与现有 `formatYuan` 体系一致）。

### 4.5 「新增」角标

满足任一即显示：

1. `isNewAddition == true`（手动/导入标记保留）  
2. `budgetAmount == 0` 且已付合计 `> 0`

### 4.6 未付合计自动计算

- **详情展示：** 有合同价时，未付合计 = `max(0, 合同价 − 已付合计)`（与仅加总「未付」付款行可并存展示时，以该公式为用户可见的「未付合计」主口径）  
- **录入/编辑付款：** 在已知合同价与已付的前提下，自动回填「未付」金额；用户可改

### 4.7 抽屉宽度

账本切换抽屉宽度 = **屏幕宽度 × 3/4**（Android `ModalNavigationDrawer` / 小程序侧滑等价实现）。

## 5. P1 · 首页

### 5.1 删除

整块「预算执行」「预计执行」双进度条及对应帮助文案。

### 5.2 合并模块（总预算为主）

单一卡片：

- **主数字：** 总预算（大号）  
- **次要：** 预计花费（`projectedTotal`）  
- **百分比：**  
  - `percent = round((projectedTotal − totalBudget) / totalBudget × 100)`  
  - `> 0` →「预计超支 X%」  
  - `< 0` →「预计节省 |X|%」  
  - `== 0` →「持平」  
  - `totalBudget == 0` → 不展示百分比，差额用金额或「—」  
- 可辅以差额金额文案  

### 5.3 不变

已花费 / 待花费展开、最近付款、FAB 等。搜索入口完整能力在 P2。

## 6. P2 · 搜索与标签图标

### 6.1 搜索

- 首页 TopBar 搜索入口 → **搜索引导页**  
- **搜索历史：** 本地全局持久化（不按账本拆分）；最近最多 **20** 条，新搜索去重置顶；支持一键清空  
- **匹配范围：** 仅当前账本预算项 **名称**（模糊包含，大小写不敏感）  
- 输入即刷新结果列表；点击进详情  
- 无输入：仅历史；无匹配：空态  

### 6.2 标签图标

- 适用范围：阶段 / 分类 / 空间  
- 来源：**预置图标库**点选，或 **相册自定义图**  
- 存储：预置存 icon key；自定义存本地文件路径/缓存（随 taxonomy prefs）  
- 展示：标签管理列表；支付清单大类头有图标则显示，无则纯文字
