# 云同步：登录、自动推送与微信账号

**日期：** 2026-08-14  
**状态：** 待实现  
**端：** Android + 微信小程序 + 已有 Spring Boot 服务  
**前置：** `docs/superpowers/specs/2026-08-13-cloud-sync-server-design.md`（账号模型、邀请、权限仍有效）  
**本 spec 覆盖并修正：** 登录放在产品流程、开发面板只切环境、读库写库、后写覆盖、微信正式登录与绑手机、CSV 已登录导入。

## 1. 目标

登录是正常用户流程，不是开发工具。服务器数据库是账本真相：用户改一条，库里对应行更新；其他人进入同一本账本时从库里拉下来看。本地 Room / 小程序 storage 只做缓存。

一人可有多本云账本。进 App 拉列表摘要 + 当前本完整数据。改完后台自动推，用户不再点「上传当前账本 / 从云端刷新」。

## 2. 已确认决策

| 项 | 选择 |
|----|------|
| 登录入口 | 「我的」：未登录显示微信登录；登录后显示账号与协作 |
| 开发面板 | 只切环境（开发/正式、USB/局域网、测通、地址）；不含登录 |
| 同步模型 | 服务端数据库为真相；本地为缓存 |
| 进 App / 回前台 | `GET /ledgers` 列表摘要 + `GET` 当前本完整快照 |
| 切账本 | 再拉那一本详情 |
| 改数据 | 本地先写，后台推那一行 |
| 不同条目 | 互不影响，均可写入 |
| 同一条目两人先后写 | **后写覆盖先写**，不返回 409 |
| 未绑定本机账本 | 「我的」出现上传；已有 `cloudLedgerId` 或服务端 import 绑定则不显示 |
| 登录后新建账本 | 立刻 `POST` 云账本并绑定 |
| CSV 导入（已登录） | 新建一本并立刻上云 |
| CSV 导入（未登录） | 只落本机 |
| CSV 导出 | 仍只导出当前本到本地文件/分享 |
| 微信登录 | 正式 SDK：小程序 `wx.login`；Android 开放平台 App 授权 |
| 绑手机 | 小程序微信手机号快速验证；Android 走微信授权能拿到的号，拿不到不拦登录，「我的」可稍后绑（不做短信） |
| 开发登录 | 仅 Debug 包 / 开发版小程序，放在「我的」登录旁，正式包没有 |
| 未登录 | 可本机使用，不调同步接口 |
| 本期不做 | CRDT / 事件日志；短信验证码；CSV 与云端互导（导出仍本地） |

## 3. 产品流程与界面

### 3.1 开发面板（摇一摇，仅 Debug）

只做：开发 / 正式、USB 转发 / 电脑局域网、测通、服务器地址。  
去掉：开发登录、退出登录、登录态作为主操作。

### 3.2 「我的」

**未登录**

- 主按钮：微信登录  
- Debug：旁路「开发登录」  
- 无上传、刷新、邀请

**已登录**

- 账号（昵称、头像）；绑定手机号入口（未绑时）  
- 邀请：生成邀请码（点击复制带 App 介绍文案）、输入邀请码加入  
- 上传：仅当**当前账本未绑云**（无 `cloudLedgerId`，且服务端没有 `(当前用户, localProjectId)` 绑定）  
- **没有**「上传当前账本」（已绑云）、「从云端刷新」

### 3.3 进 App / 回前台（已登录）

1. 拉账本列表摘要（云端 id、名称、角色）  
2. 拉当前正在看的那一本完整快照，覆盖本地该本缓存  
3. 列表里其它本等用户切过去再拉详情  

新手机登录后，列表来自服务器，因此能看到其它云账本。

### 3.4 写路径（已登录且已绑云）

改预算项、付款、账本名等：界面立刻用本地结果；后台把对应行写到服务器。失败 toast，本地改动保留，下次进 App / 回前台再试推。

登录后点「新建账本」：先在服务器建空本，本地绑定 `cloudLedgerId`，之后同上。

### 3.5 邀请

加入成功后本地带上对方的 `cloudLedgerId`，视为已绑云，不显示上传。邀请文案与复制行为保持现有「含 App 介绍」。

## 4. 如何判断「是不是同一本账本」

不靠账本名称。

| 状态 | 判定 | UI |
|------|------|-----|
| 本地有 `cloudLedgerId` | 已绑该云账本 | 不显示上传 |
| 无 `cloudLedgerId`，但服务端有 `(userId, localProjectId)` import 绑定 | 曾经传过 | 按绑定恢复，不显示上传 |
| 两边都没有绑定 | 本机未上云 | 「我的」显示上传 |
| 邀请加入 | 加入接口返回云端 id | 已绑云 |

两本都叫「我家装修」仍是两本。

## 5. 同步与冲突（修正 2026-08-13 §8.4）

**读：** 进本账本 = 从数据库拉这本当前内容。乙看到的是库里已有的行，包括甲已经写成功的修改。

**写：** `PUT` 一项（含其付款）更新数据库对应行。不要用**整本 `revision` 不一致就 409**——那会让两人改不同条目也失败。

**同一行：** 后到的请求覆盖先到的。先写的人下次进入该账本才看到被改。本期不做 409、不做弹窗选「留我的 / 用云端」。

账本级 `revision` 若仍保留，只作「有过写入」的计数或列表展示，**不得**作为拒绝不同条目写入的条件。

推送失败（网络、5xx）：toast；401 清登录态并引导去「我的」登录。

## 6. 微信登录与手机号

### 6.1 登录

- 小程序：`wx.login` → `POST /auth/wechat`（client=`mp`）→ JWT  
- Android：微信开放平台移动应用授权 → 同一接口（client=`app`）→ JWT  
- unionid 相同则同一 `User`；否则分身份存储，**绑定同一手机号后合并为同一 User**  
- 正式包：只有微信登录。Debug / 小程序开发版：「我的」可另有开发登录（`POST /auth/dev-login`，服务端开关）

### 6.2 绑手机

- 小程序：微信手机号快速验证，把凭证交给 `POST /auth/bind-phone`  
- Android：授权流程中若能拿到手机号则绑定；否则不拦登录。「我的」可再发起一次微信授权取号。若开放平台未开通该权限，入口说明「请在微信小程序中绑定手机号」。**不做短信验证码**  
- 号已绑其他账号：拒绝，文案「该手机号已被使用」  
- 未绑手机可以使用账本、邀请、同步

微信 AppId / Secret、开放平台签名、小程序服务器域名在实现计划中列出配置项，不写进业务逻辑。

## 7. CSV

| 场景 | 行为 |
|------|------|
| 未登录导入 | 沿用现有批量导入，写入**当前本机账本** |
| 已登录导入 | **新建一本账本**（不并入当前本），写入导入数据，再对该本 `POST /ledgers/import` 上云 |
| 导出 | 只导出**当前这一本**到本地文件或分享，不经过服务器另下一份 |

CSV 不作为多人同步通道。

## 8. HTTP 接口（相对现状）

已有且继续用：`POST /auth/wechat`、`POST /auth/bind-phone`、`POST /ledgers/import`、`GET /ledgers/{id}`、`PUT`/`DELETE` 项、邀请加入、开发登录（仅开发环境）。

**必须补齐或接上客户端：**

| 用途 | 方法与路径 |
|------|------------|
| 账本列表摘要 | `GET /ledgers` |
| 新建空账本 | `POST /ledgers`（body：name） |

**必须改行为：**

- `PUT /ledgers/{id}/items/{itemId}`：成员即可写；**不要**因整本 `baseRevision` 不匹配而 409。后写覆盖该条。  
- 删除项：重复删除视为成功。

import 仍用于：未绑定本机账本的手动上传、已登录 CSV 导入（新 localId，禁止并入当前本）。登录后点「新建账本」走 `POST /ledgers` 空本。

## 9. 客户端改动摘要

**Android / 小程序对等**

- 开发面板去登录；「我的」承担微信登录、绑手机、邀请、未绑定上传  
- 进前台 / 进总览：已登录则拉列表 + 当前本  
- 写操作后自动推该项（已绑云）  
- 新建账本（已登录）先云后本地绑定  
- 接入微信 SDK；Debug 保留开发登录  
- Loading / Toast：登录、上传未绑定本、邀请、推送失败时要有

## 10. 测试与验收

**服务端**

- 列表返回该用户为成员的账本；非成员 403  
- 新建空账本后 GET 为空项  
- 两人先后 PUT 不同 itemId 均 200  
- 两人先后 PUT 同一 itemId：后者 body 成为 GET 结果  
- import 对同一 `(user, localId)` 不重复建账本  
- 微信登录用测试替身；绑号冲突 409 文案  
- 正式配置下 `dev-login` 关闭

**客户端（可测部分 + 手工）**

- 未登录不请求账本接口  
- 已登录进页拉列表与当前本  
- 无 `cloudLedgerId` 显示上传；绑定后按钮消失  
- CSV 已登录导入后出现新云账本  
- Debug 面板无登录按钮；「我的」有微信登录  

**手工验收**

- 小程序微信登录 + 取手机号  
- Android 微信授权登录；无手机号时仍能进账本，可稍后绑  
- 两人同一本：甲改橱柜、乙改地板，各自进页能看到对方已成功的写入  
- 两人改同一条金额：后保存的覆盖，先保存的人再进页看到新值  
- 邀请加入后无「上传」按钮  

## 11. 明确不做（本期）

- CRDT、事件日志、自动合并金额字段  
- 同条 409 / 「保留我的 vs 云端」弹窗  
- 短信验证码登录或绑号  
- 进 App 拉每一本完整快照  
- 用账本名称匹配是否同一本  
- 把开发登录做进正式包或开发面板主路径  
- Google / Apple 登录、iOS 客户端
